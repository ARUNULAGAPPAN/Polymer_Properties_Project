Molecular Fingerprinting: Converts chemical structures into numerical descriptors (Molar Mass, LogP, TPSA).

📊 Methodology
Data Encoding: Polymers are entered via SMILES (Simplified Molecular Input Line Entry System).
Feature Extraction: RDKit calculates four critical descriptors:
MolWt: Overall chain mass.
LogP: Hydrophobicity/Chemical resistance.
Rotatable Bonds: Chain flexibility.
TPSA: Polar surface area (bonding potential).
Inference: The Random Forest models (trained on polymer physics correlations) process these features to output
